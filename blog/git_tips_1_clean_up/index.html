git提交历史整理

13 May.

最近 CLion 对非商业使用免费了.在 cursor 的帮助下, 做了个 CLion 环境下(用 CMAK 管理) leetcode c 语言的题解框架 自用.

边做边摸索,今天大致成型.回头看到太多临时和凌乱的提交,想整理一把.

第一步是备份,git 的分支是零成本的,所以搞一个备份分支.注意我们这里是搞分支,不是切分支,不要无脑 checkout -b,用 branch 命令够了.

git branch masterarchive20250513

接着把大量的混乱提交全部干掉,压缩到一个提交里面

使用一个凶残的命令

git rebase -i --root

这个时候自动打开的编辑器(比如 vi),显示如下:

除了保持第一行初始提交 pick 的状态不变,其他提交改成 s(squash)或者 f(fixup),这里我们删除掉所有的后续提交信息,选择用 f

vim 命令模式下输入

 :2,$s/pick/f/g

将第二行开始的 pick 全部替换成 s.

wq 保存后退出,执行.

最后提交变成一个.

接着要将一个提交拆成两个,第一个提交为框架的代码,第二个为示例题解的代码.从第一个图上,我们知道示例题解程序代码放在 problems 下.

因为目前代码仓库比较特殊,只有一个初始提交,所有常规 reset –soft 等方法将不好使.

这个时候使用

git rm -r --cached -- problems

来把 problems 整个目录从版本仓库和暂存区删除,problems 的状态变成待加入暂存区的状态(工作区有一份),状态见图:

这个时候,第一步用

git commit --amend --no-edit

方式把 problems 从第一个提交中剔除

第二步就是常规的 add & comit 了
